# Blinkit Grocery Sales — SQL Analysis

Exploratory SQL analysis of grocery sales data across items and outlets.

## Overview
- **Dataset:** Grocery sales records with item weight, fat content, type, MRP, outlet type/size/location, and sales figures
- **Approach:** Built a normalized `grocery_sales` table and wrote queries covering item counts, price/weight distributions, fat-content breakdowns, and outlet-level sales patterns

## Tools
MySQL
